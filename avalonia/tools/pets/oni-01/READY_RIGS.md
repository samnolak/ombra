# Готовые риги: проверенные варианты

Проверено 14 октября 2026. Это альтернативы для исследования, а не подключённые зависимости.

- [Spineboy — официальный проект Spine](https://esotericsoftware.com/spine-examples-spineboy): есть скачиваемый проект, меши, IK, ограничения трансформаций и clipping. Документация подробно показывает иерархию таза и независимых целей стоп, порядок IK для голени и стопы. Это конкретная готовая основа для изучения рига; перенос на ONI всё равно потребует подготовки его деталей и настройки пропорций. Совместимость с ONI не проверена.
- [DragonBones Mecha, данные скелета](https://github.com/DragonBones/DragonBonesJS/blob/master/Pixi/Demos/resource/mecha_1406/mecha_1406_ske.dbbin): готовый робот в примерах DragonBones. [Репозиторий художественных демо](https://github.com/DragonBones/Demos) указывает CC BY-NC-SA 4.0, поэтому нельзя автоматически считать демонстрационную графику пригодной для распространения с продуктом. Пока только референс, не включён в Ombra.

Текущий выбранный путь — цельные кадры. Чужой скелет сам по себе не исправит неудачные исходные детали, неверный ракурс или актёрскую постановку. Если возвращаться к ригу, сначала сделать один короткий проверяемый этюд на готовом проекте и корректно подготовленных слоях ONI, не размножать состояния и не внедрять до проверки.
