# ONI-01 — компактная поставка runtime

Только активные PNG, геометрия/тайминги JSON и эталонная логика событий, физики и эффектов. Никаких видео, HTML с base64, старых поколений графики, этюдов или проверочных листов в ресурсы приложения копировать не нужно.

`node verify-package.cjs` проверяет целостность. Инструкция интеграции AGENT_TASK.md и просмотрщик находятся в полном handoff-пакете; этот каталог предназначен для отбора production-ресурсов. JS — эталон для переноса в Avalonia, не готовый нативный плагин.

PNG сжаты без потерь; PNG_OPTIMIZATION.json фиксирует сравнение каждого декодированного RGBA-буфера. Размеры, alpha, якоря, кадры и тайминги сохранены. Цветовая палитра не урезана.

Декодировать каждый уникальный source один раз и переиспользовать между входом и циклом. Не создавать текстуру на каждом кадре; загрузить до первого проигрывания, рисовать source-rect. Освобождать кеш при выгрузке питомца. Физика/FX получают dt в секундах, таймлайн кадров — миллисекунды.

Сжатие PNG уменьшает диск/передачу, но не размер декодированных RGBA. Нативную память, FPS и время декодирования необходимо измерить после внедрения; браузерная подготовка не доказывает эти показатели.
