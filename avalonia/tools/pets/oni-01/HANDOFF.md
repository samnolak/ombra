# ONI-01 — контракт передачи для Ombra

Статус: **пакет подготовки к внедрению, версия 15 октября 2026**. Содержит эталонный проигрыватель, кадры, эффекты, контракт событий и проверочные записи. `HANDOFF_PLAN.md` фиксирует фактические проверки и их границы; `QA.md` — история. Нативное приложение в рамках подготовки не изменялось; приёмка Avalonia выполняется агентом внедрения по списку ниже.

## Запуск

Из каталога пакета: `node serve-preview.cjs`, затем http://127.0.0.1:4186/ . При занятом порте задайте `ONI_PREVIEW_PORT=4188`. Просмотрщик загружает внешние PNG из поставки; зависимости npm для запуска не нужны. Запускать через сервер, не через file://. Кадры и видео сохраняются в локальный `exports/`. `manifest.sha256.json` содержит длины и SHA-256 всех файлов поставки; запуск `node verify-package.cjs` проверяет их. Начните с `AGENT_TASK.md`: там порядок внедрения и критерии приёмки.

## Неизменяемый дизайн

Робот в жёсткой маске они. Нет зрачков; бело-розовое ядро глаз с красным свечением. Рот, клыки и челюсть не артикулируются. Нет хвоста и верёвки сзади; короткая петля на шее с оборванным передним концом. Упрощённые пластины без узоров на бёдрах; на ноге серебристые бедро и ботинок, без дополнительной белой секции голени. Контуры должны разделять перекрывающиеся детали в миниатюре.

Радость: кулачки рядом со щеками, торс плавно качается относительно таза, стопы остаются на земле. Текущий цикл — 64 цельных кадра за 2,8 с. Скелет в runtime не используется. `joy-torso.cjs` — только авторинг запечённых кадров.

## События и приоритеты

| Источник | Событие эталона | Поза / срок |
|---|---|---|
| Нет работы | idle | idle, сон после 180 с без активности |
| Модель думает или пишет | thinking | thinking |
| Инструмент выполняется | working | working с ноутбуком |
| Вопрос или разрешение | waiting | waiting до ответа / нового базового состояния |
| Завершён непрерванный запуск | done | joy, затем актуальная база |
| Ошибка инструмента | tool-error | error на 2,4 с от события |
| Постоянный Faulted | error | error до нового базового состояния |
| Отмена | abort | idle, без радости |
| Ввод / клик | type / click | пробуждение и внимание, не скрывают waiting/error |
| Захват / посадка | drag-start / land | dragging поверх состояния; при посадке восстановить последнее |

Приоритет: перенос → постоянный вопрос/ошибка → временная реакция → работа/размышление → покой/сон. Эффекты важного состояния реагируют сразу, пока тело заканчивает переход. Новая работа отменяет устаревшую радость.

**Отличие от текущего PetMoodMachine:** эталон считает 2,4 с радости после достижения её основного цикла, чтобы уборка ноутбука не съедала всю реакцию; абсолютный предел — 8 с после done. Адаптеру нужны исходные события завершения и ошибка инструмента, а не только итоговый enum Mood. Не менять общие таймеры других питомцев ради ONI.

## Рендер и геометрия

`frames/approved-v1/manifest.json` перечисляет PNG, SHA-256, прямоугольники `sx/sy/cw/ch`, опорные точки и тайминг. `clip.keys` — длительности в **миллисекундах**; Director/физика — **секунды**. Не воспроизводить весь лист с произвольным FPS: у обычных циклов есть выдержки и обратный проход. Радость имеет полный цикл и нейтральные кадры 0/32; выход продолжает движение вперёд к ближайшему нейтральному кадру.

Позиция кадра: масштаб `logicalHeight * state.scale`, смещение по `anchorX/anchorY`. Idle привязан к земле, dragging — к голове. Переходы описаны `transitions/manifest.json`, масштаб `logicalHeight / referenceHeight`. Вопрос использует явно заданную sequence; исключённые рисунки не возвращать. Измерение ширины головы — техническая калибровка, **не доказательство совпадения рисунков на стыках**.

Порядок: задний FX-проход → тело/реквизит → передний FX-проход. Пыль посадки перед ботинками; круг работы и повторяющийся глитч ошибки сзади по центру; духи меняют слой при обходе тела. Весь FX-код и параметры находятся в `effects-player.cjs`, динамика в `interaction.cjs`. Общие часы духов не сбрасываются при смене состояния.

Духи: спокойный полёт в idle; небольшие радостные подскоки; орбита помощников в работе; медленный облёт при размышлении; пульсация внимания при вопросе; скрытие во сне; паника при ошибке; быстрые X-орбиты при переносе. Ворота не вызываются. Знаки: точки / ? / !! / растущие улетающие z/Z по смыслу.

Drag: захват у верхней части тела, низ отстаёт при ускорении; предел наклона около 10°. Не накладывать одновременно нативную и эталонную физику. Порог жеста 6 логических единиц; pointer cancellation никогда не открывает чат. После потери захвата безопасно отпустить тело.

## Точки подключения Avalonia

Пути относительно `avalonia/src/Ombra.App`:

- `Pets/PetFrames.cs`: семь PetMood. ONI требует отдельного проигрывателя PNG, существующие пиксельные питомцы остаются на прежнем пути.
- `ViewModels/PetsViewModel.cs`, `Pets/PetMoodMachine.cs`: mapping и события из OnSnapshot, ввод/Poke, разделение временной и постоянной ошибки.
- `Controls/PetView.cs`: рендер, Attention/Animate/Foreground, hover/click. Не применять старые движения зрачков и рта PetLife к маске ONI.
- `Controls/PetStage.axaml.cs`, `PetPerch`, `PetWindow`, `Pets/PetDesktop.cs`: захват, размещение, хит-тест, экранные края, пузырь и чат.
- `Pets/PetLife.cs`: старые остановки Error/Waiting/Sleeping через 20/60/40 с несовместимы с непрерывными ONI-эффектами. Использовать отдельную политику.

Текущие small/medium дают 32/48 логических единиц высоты. Не считать просмотр на 128 доказательством читаемости этих размеров. У эффектов есть отдельная светлая палитра; тема должна приходить от приложения. Reduced-motion использует осмысленную статическую позу, сон — конечную, с убранными духами. При скрытии остановить отрисовку; при возврате учесть прошедшее время для семантических сроков, ограничить dt анимации/физики.

## Обязательная проверка после внедрения

Прозрачность и свечение на светлом/тёмном фоне; масштаб 32/48 и дополнительные размеры; DPI 100/150/200%, смена мониторов; края окна без обрезки духов/дыма/символов; каждый PetMood; временный и постоянный error; отмена без радости; прерывание входов/выходов вопросом и ошибкой; drag из всех состояний и событие во время переноса; потеря захвата; click открывает чат ровно один раз; ввод/hover пробуждают; reduced-motion, скрытие/возврат, освобождение таймеров и текстур. Браузерные тесты не заменяют эти проверки.

## Проверка кандидата автономно

Node.js 22 или новее. После `node verify-package.cjs` выполнить:

```sh
node --test states.test.cjs interaction.test.cjs input.test.cjs scenario.test.cjs registration.test.cjs export-store.test.cjs serve-file.test.cjs preview-clock.test.cjs
```

Эти тесты не требуют npm-зависимостей. Авторский `joy-bake.test.cjs` в рабочем проекте дополнительно проверяет пиксели PNG через Sharp; он не нужен для запуска поставки. Нативную реализацию этими командами не проверяют.

Актуальные записи: [сценарий](exports/oni-scenario-7e5bf55fedc1.webm), [перенос на светлом фоне](exports/oni-drag-dynamics-bc5ffe2ebe50.webm), [все состояния на светлом фоне](exports/oni-approved-states-4a043f9b8e79.webm). [Прерывания и смена состояния в переносе](exports/oni-interruptions-bfccdf5f20da.webm). Страница http://127.0.0.1:4186/review позволяет выбирать и перематывать все четыре записи. [Матрица размеров всех состояний](exports/oni-size-comparison-5c6daea3a72c.png) использует статические позы; она не доказывает качество движения.

Размер ONI: художественный минимум **64 логических px**, предпочтительно 80–96. На 32/48 рисунок технически воспроизводится, но теряется мимика и детали духов; это не рекомендуемые размеры ONI. Не менять размеры остальных питомцев: адаптер должен поддерживать собственные размеры персонажа вместо механического наследования 24-pixel PetFrames.

Текущая версия 15 октября: радость v11 запечена из кадра 7 joy-entry, вход заканчивается на нём. Остальные циклы используют последние четыре целых рисунка своих входов; конец входа и начало цикла имеют одинаковые исходник, прямоугольник, якорь и масштаб. Это устраняет прежнюю замену позы на стыке. Старые независимые PNG циклов сохранены в рабочей истории и не нужны активному runtime.

## Облегчённая поставка

Для приложения использовать отдельный `runtime/` или `oni-01-runtime-2026-10-15.zip`: только 12 активных PNG, JSON и эталонная логика. Полный handoff содержит видео и доказательства для проверки — не включать их в ресурсы приложения. PNG сжаты без изменения RGBA; общий source входа/цикла декодировать один раз. Подробности — OPTIMIZATION.md.
