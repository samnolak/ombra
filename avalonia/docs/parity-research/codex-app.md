## Notes

**Upstream omp asks (нужны для паритета, клиент их не обходит):**
- RPC для plan mode, `/goal` (с событиями прогресса/таймера/паузы), `/btw` (side chat), `/fork` и `/tree` (`navigateTree`), `/live` — сейчас всё TUI-only (PARITY §5). Это крупнейший разрыв с Codex app (Goal mode GA 26.519, plan-вопросы с уведомлениями 26.317, fork с любого сообщения 26.317).
- Trust-модель для проектных hooks/extensions (аналог «Servers from project files» для MCP) — Codex добавил trust review в 26.506.
- `set_event_filter`/`session_settled` (ROADMAP backlog) — убирает квадратичную стоимость стрима; прямой аналог их фиксов 26.228/26.205.
- Auto-review reviewer и per-app доступ Computer use — только если omp введёт; GUI-карточки делать после.

**Что можно сделать без omp-изменений (штатный RPC/CLI):** host-tool `terminal_read` через `set_host_tools` (26.311); remote-агент через `ssh host omp --mode rpc-ui` (stdio-транспорт не меняется); импорт через `--from-claude/--from-codex`; PR-бейджи через `gh`; PDF-превью через уже встроенный WebView.

**Конфликты шорткатов с раскладкой Codex** (которую пользователи переносят мышечной памятью): у нас `⌘⇧P` = Plan, `⌘⇧T` = Background tasks, `⌘⇧F` = Files, `⌘⇧B` = Browser (`MainWindow.axaml.cs:634-636`, `KeyboardShortcuts.For`); у Codex `⌘⇧P` = command menu, `⌘⇧T` = reopen tab, `⌘⇧F` = full view, `⌘⇧B` = layout cycle, `⌘⇧E` = file tree, `⌃⇧G` = review. Решить до релиза, пока раскладка не устоялась; добавить `⌘K` под палитру.

**Риски:**
- P0 подписи macOS (см. Bug classes) — самая срочная позиция: приложение запрашивает Screen Recording/Accessibility для Computer use и сохраняет их между версиями благодаря стабильному DR, а hardened runtime в используемой сейчас self-signed ветке не включён.
- Нет single-instance: двойной запуск → два набора omp на одних файлах сессий/`session-pins.json`.
- Удаление — единственный способ «убрать» сессию (нет archive) → риск потери данных пользователем.

**Скоуп источника:** iOS-записи пропущены по заданию, но их баг-фиксы (переподключение с восстановлением approvals, сохранение первого промпта при старте задачи, «Canceling or editing a steering message now prevents delivery», «Fixed stale queued messages when switching from Queue to Steer», модель/Fast «scoped to the current task») — тот же класс, что и наш RPC-клиент; стоит сверить с нашими Queue/Steer и рестартами при разборе CLI/iOS-отчёта.
