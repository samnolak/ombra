## Notes

- **Документация отстаёт от закреплённого omp 18.8.0.** PARITY.md §3–§5 и ROADMAP.md:119-122/PROJECT_STATE.md:160 считают TUI-only или «ждём апгрейд» то, что 18.8.0 уже отдаёт по RPC: `promote_queued_message`, `abort_and_restore_queue`, `cancel_subagent`, `steer_subagent`, `fork`, `get_tree`, `goal`, `btw`/`btw_cancel`/`get_btw_history`, `set_cache_warming`, `set_slow_mode`, `set_todos`, `abort_retry`, `set_event_filter` (delta) — все найдены как `case "…"` в `rpc-mode.ts` 18.8.0 (строки 1908, 1921, 1953, 2086, 2119, 2126, 2187, 2228, 2243, 2348, 2365, 2575, 2580). Это самые дешёвые P1/P2-победы: перевод «Via omp terminal» → нативный UI без апгрейда omp. Нужен проход по PARITY с перепроверкой.
- PROJECT_STATE.md:159 «One omp process (one live session) at a time» противоречит коду (`MainViewModel.OpenSessions.cs:11-18`, несколько чатов параллельно) — устаревшая строка.
- **Upstream-запросы к omp:** RPC для отмены background job (`/jobs` даёт только список; `abort_bash` — лишь для `!cmd`); MCP OAuth sign-in по RPC; блокировка файла сессии от второго писателя (если её нет); установка npm-плагинов с `--ignore-scripts` + проверка integrity (CC 2.1.275) — omp-core, `install`/`plugin` идут через omp CLI; событие «MCP server disconnected, reconnection gave up» (CC 2.1.273), чтобы GUI показал баннер.
- **Риски:** UNC-превью (P0) затрагивает только Windows, но срабатывает без клика, по наведению на текст, который может прийти из веб-страницы через агента. Git clean-filter (P1) — любой открытый непроверенный репозиторий; доверие к папке у клиента не спрашивается [INFERENCE: trust prompt не найден].
- **Оптимизации (направление 3) из этого диапазона CC:** delta-стриминг (`set_event_filter`), отказ от полного `Snapshot()` на каждый кадр, кэш usage между чатами (уже 30 s per window — можно сделать общим для всех чатов процесса), отложенная проверка обновлений после старта (CC 2.1.238: +10 s), не держать фоновые чаты в полном apply (уже есть).
- Не проверялось (Unclear, без утверждений): CMYK JPEG и WSLg clipboard-вставка картинок, RTL в composer, клик-активация окна, mapped/SUBST диски, поведение dictation при отказе сервиса.
